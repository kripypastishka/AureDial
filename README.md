# AureDial

Нативная звонилка для Android 10 и новее. Текущая версия — **0.2.0-beta04**, тестовая сборка.

- Экран звонка с ответом, отклонением, удержанием, DTMF и выбором аудиовыхода. Доступность действий зависит от возможностей Telecom и оператора.
- Контакты, избранное, поиск T9 по кириллице и латинице, журнал с фильтрами пропущенных и заблокированных звонков.
- Белый и чёрный списки, блокировка из карточки звонка, необязательное отключение звука при явном провале проверки номера оператором.
- Офлайн-диктор при входящем вызове. Можно ограничить озвучивание сохранёнными контактами, выключить его или настроить скорость речи.

## Сборка

Нужны JDK 17, Android SDK Platform 36, Build Tools 35.0.0 и Gradle 8.13.

```sh
gradle :domain:test :app:lintDebug :app:assembleDebug
```

Debug APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions запускает те же проверки и сохраняет APK в артефакте `auredial-debug`. Установка поверх предыдущей сборки требует той же подписи. Скрипт `scripts/emulator-smoke.sh` проверяет клавиатуру, уведомление, вызов TTS из фона, экран блокировки, приём из системного уведомления, завершение разговора и навигацию на Android 15.

### Подпись тестовых APK

Для обновлений поверх сборки с постоянной тестовой подписью используй один и тот же закрытый keystore. Передавай Gradle путь и параметры через переменные среды `AUREDIAL_KEYSTORE`, `AUREDIAL_STORE_PASSWORD`, `AUREDIAL_KEY_ALIAS` и `AUREDIAL_KEY_PASSWORD`. Без этих переменных работает стандартная debug-подпись. Храни ключ и пароли отдельно от репозитория.

## Настройка

Для приёма вызовов назначь AureDial приложением «Телефон» по умолчанию и разреши уведомления. Фильтрация включается отдельно на экране «Защита» и требует системной роли фильтра звонков. Приложение обращается к контактам и журналу через Android, хранит настройки локально и не запрашивает разрешение на интернет.

Текущие ограничения и проверяемые сценарии описаны в [PROJECT_STATUS.md](PROJECT_STATUS.md).
