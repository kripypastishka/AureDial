# AureDial · 0.1.0-alpha01

Начальная инженерная итерация нативной звонилки Android. Не готова к эксплуатации. Не назначайте ее фильтром на основном телефоне: назначение заменяет текущий системный фильтр, а качество работы на устройстве еще не подтверждено.

## Сборка
JDK 17, Android SDK Platform 36, Build Tools 35.0.0 и Gradle 8.13.

```sh
gradle :domain:test :app:lintDebug :app:assembleDebug
```

APK при успешной сборке: `app/build/outputs/apk/debug/app-debug.apk`. CI использует установленный Gradle. Debug APK не требует секретов. Release не подписан и не проверен.

## Проверка
В исходной среде 15/15 независимых проверок доменной логики прошли. Android lint, Android build и физическое тестирование не подтверждены.

## Безопасность
Нет интернет-разрешения, доступа к журналу звонков, контактам, микрофону, SMS. Правила хранятся в приватном хранилище; backup выключен; это не шифрование. TTS только с локальным голосом. Не предоставляйте роль фильтрации вне тестового устройства.
